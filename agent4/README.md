# Agent 4 - CPU Frequency & Dynamic Scaling AI Agent

Monitors and scales CPU Core Frequencies, Dynamic Voltage & Frequency Scaling (DVFS), and Governor modes across **Laptops, Desktops, Drones, and IoT Edge Devices**.

## Usage
```bash
cd agent4
python3 main.py --test-run
python3 main.py --web --port 8004
```
